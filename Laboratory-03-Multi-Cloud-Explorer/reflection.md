# Reflection

Among the three cloud platforms that I explored, Amazon Web Services (AWS) impressed me the most. AWS provides a wide range of services for computing, storage, databases, networking, security, and other cloud computing needs. I was especially interested in services such as Amazon EC2, Amazon S3, and Amazon RDS because they show how organizations can build and manage different parts of their systems using cloud resources.

While researching AWS, Microsoft Azure, and Google Cloud Platform, I noticed that they have many similarities. All three provide virtual machines, object storage, databases, networking, identity management, and Kubernetes services. Although the names of their services are different, many of them perform similar functions. This helped me understand that knowledge of basic cloud concepts can be applied across different cloud providers.

I also learned that business requirements are important when choosing a cloud platform. There is no single provider that is always the best choice. For example, Azure can be suitable for organizations that already use Microsoft technologies, while Google Cloud can be a strong choice for AI, machine learning, and Kubernetes workloads. AWS can be useful for organizations that need a broad selection of scalable cloud services.

Through the role of a Cloud Solutions Consultant in this activity, I learned that recommending a cloud platform requires understanding the client's needs before selecting technologies. Factors such as existing systems, budget, scalability, application requirements, and future growth should be considered when designing a cloud solution.

Finally, maintaining my work through a GitHub portfolio improved my understanding of technical documentation and version control. Creating Markdown files, organizing laboratory folders, committing changes, and pushing them to GitHub helped me practice documenting my work in an organized way. This activity showed me that cloud computing also requires research, comparison, decision-making, and clear technical documentation.
