
# Mission Reflection

Completing this laboratory activity helped me understand how a host-based firewall provides another layer of security for a server. Even if an attacker gets past the main network firewall, UFW can still restrict incoming connections to the individual server. This showed me why having multiple layers of security is important in cloud computing.

I learned that managing open network ports is necessary because every unnecessary open port can become a possible entry point for attackers. During this activity, I configured UFW to deny incoming traffic by default while allowing SSH and port 8080 for the Nginx web application. This helped me understand how to allow legitimate connections while reducing security risks.

Leaving a database port such as MySQL port 3306 open to the public internet can be dangerous because attackers may attempt unauthorized access, password attacks, or exploitation of vulnerabilities. In an enterprise environment, databases should only be accessible to trusted applications and authorized users.

Before this mission, I thought deploying a working server was already enough. However, I realized that even if a website is functioning properly, the server could still have security weaknesses. This activity taught me that securing a server is just as important as deploying and maintaining it.

From basic cloud fundamentals to container deployment, monitoring, and security, I can see how my technical knowledge has improved.
