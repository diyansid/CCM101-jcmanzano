# Laboratory 05 – Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on cloud data storage and the differences between Block Storage, File Storage, and Object Storage. As part of the activity, I deployed MinIO using Docker in a KillerCoda Linux environment to create an S3-compatible object storage server.

The practical activity involved accessing the MinIO Web Console, creating a private bucket named `client-photos`, and uploading a sample image to demonstrate how objects can be stored in a cloud storage environment.

## Objectives

- Differentiate between Block, File, and Object Storage.
- Understand common use cases for different cloud storage types.
- Deploy an S3-compatible MinIO Object Storage server using Docker.
- Access a containerized cloud service through a web interface.
- Create an object storage bucket and upload a file.
- Document cloud storage operations using Markdown and GitHub.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- MinIO Object Storage
- Git and GitHub
- Web Browser
- Markdown

## Skills Learned

Through this laboratory activity, I practiced deploying and managing a containerized object storage service using Docker. I learned how Docker ports and environment variables are used when configuring a container and how MinIO provides S3-compatible object storage.

I also gained experience creating storage buckets, uploading objects through a web-based management console, verifying running Docker containers, documenting technical procedures in Markdown, and maintaining laboratory work using Git and GitHub.
