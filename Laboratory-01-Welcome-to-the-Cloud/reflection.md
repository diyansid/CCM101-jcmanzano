# Reflection

This laboratory activity helped me understand the basic environment used in cloud computing. I learned how to access an Ubuntu Linux environment through KillerCoda and use different Linux commands to navigate the system and gather important system information.

I also learned how to organize files and directories using Linux commands. Creating Markdown files helped me understand the importance of documenting technical work clearly and professionally.

Another important part of the activity was creating a GitHub repository for my Cloud Computing portfolio. This showed me how GitHub can be used to organize and maintain laboratory activities throughout the semester.

Overall, this laboratory provided me with a foundation in Linux, cloud environments, file organization, Markdown documentation, and GitHub. These skills will be useful as I continue learning about cloud computing and cloud infrastructure.
