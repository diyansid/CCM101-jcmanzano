# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the fundamentals of working in a cloud-based Linux environment. It involves accessing KillerCoda, exploring the Linux operating system, gathering system information, organizing files and directories, and creating a Cloud Computing portfolio using GitHub.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

## Activities Performed

I accessed an Ubuntu Linux environment through KillerCoda and created a new Linux user account. I explored the Linux environment and gathered information about the operating system, kernel, CPU, memory, and disk space. I also created and organized directories and Markdown files for my Cloud Computing portfolio.

## Linux Commands Used

- `whoami` – displays the current username.
- `pwd` – displays the current working directory.
- `hostname` – displays the hostname.
- `cat /etc/os-release` – displays Linux distribution information.
- `uname -r` – displays the kernel version.
- `lscpu` – displays CPU information.
- `free -h` – displays memory information.
- `df -h` – displays disk space information.
- `mkdir` – creates directories.
- `cd` – changes directories.
- `nano` – creates and edits text files.
- `cat` – displays file contents.
- `ls` – lists files and directories.
- `find` – searches for files and directories.

## Skills Learned

Through this laboratory activity, I learned how to access and work inside a cloud-based Linux environment. I also learned how to use basic Linux commands, gather system information, organize files and directories, create Markdown documentation, and use GitHub as a portfolio for my Cloud Computing activities.
